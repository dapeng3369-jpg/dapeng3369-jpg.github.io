公司注销后印章怎么处理：上交、封存还是销毁（嘉兴）

注销登记完成后，印章不能随手丢弃，也不能转手他人。常规做法是把印章上交对接网点或按网点要求封存、销毁，并留存交章或销毁凭证——这份凭证在后续被冒用、涉诉时是唯一的自证材料。具体交章要求以当地公安机关与对接网点当次告知为准。

什么情况下需要它

  • 企业注销登记完成
  • 分支机构撤销
  • 公章被他人持有、需要收回处理

办理顺序

  1. 完成市场监管注销登记，取得注销核准材料
  2. 清点在册印章：公章、财务章、法人章、合同章、发票章，逐一核对编号
  3. 按网点要求上交或封存销毁，并索取凭证
  4. 留存注销材料与交章凭证，至少保存至法定期限
  5. 若印章曾被用于对外签约，同步通知合同相对方

最容易踩的坑

  • 注销前把章借给他人使用，是后续纠纷里最常见、也最难自证的情形
  • 清点时按编号核对最可靠：专用章按规定须用阿拉伯数字区别，台账与实物要能一一对应

需要的材料

  • 营业执照副本（新设企业可用名称预先核准材料）
  • 法定代表人身份证（原件或按网点要求的清晰件）
  • 经办人身份证 + 授权委托书（经办人非法定代表人时）
  • 变更过名称的企业：准予变更登记通知书
  • 遗失补刻：按网点要求的遗失声明材料

交章与销毁不涉及刻制费用；如需重新刻制按公示价执行（公章110、财务章90、法人章65）。
